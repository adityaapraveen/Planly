# Planly web client

The Planly client is a React and Vite application for project management, drawing upload, AI review, evidence overlays, and human finding triage.

Use the repository [README](../README.md) for complete setup, architecture, API, security, and validation instructions.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

Copy `.env.example` to `.env` and set `VITE_API_URL` to the backend origin.
